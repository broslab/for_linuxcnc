### Программы обработок для LinuxCNC

### ScrewOnLathe
Проточка трёхзонного шнека на токарном станке, <br />
плюс добавлена зона для выхода резца. <br />
Глубину прохода выбирать так чтоб глубина канавки <br />
делилась на глубину прохода нацело. <br />
Смещение резца по такому же принципу. <br />
